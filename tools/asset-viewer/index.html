"What the game sees" boots the published game itself (kingmarkarnold-code.github.io/adamsville-play/detailed/) inside this page and places the asset in its world — when the game updates, this page shows the update. "Inspect" is a close-up studio turntable (the game's own three.js and model files, plain background) for studying shape — it is not the game view. Code-built animals (birds, squirrel, chipmunk, butterflies) have no model files — they are built by code inside the game — so in "What the game sees" the game's own builders place the real animal in front of you, while "Inspect" can't show them; if a game build ever lacks a builder, that one animal falls back to an honest card.
